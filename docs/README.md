# memex docs

Docs have moved to [**quefly.com/docs/memex**](https://quefly.com/docs/memex).

This `docs/` folder is kept as the historical source. For the current
documentation, install guide, OMP spec, and screenshots, see the Quefly
site.

For the install one-liner:

```bash
# Mac
pipx install https://github.com/queflyhq/memex/releases/latest/download/memex-1.0.0-py3-none-any.whl && memex init

# Windows (PowerShell)
pipx install https://github.com/queflyhq/memex/releases/latest/download/memex-1.0.0-py3-none-any.whl; memex init

# Linux
pipx install https://github.com/queflyhq/memex/releases/latest/download/memex-1.0.0-py3-none-any.whl && memex init
```

See [INSTALL.md](../INSTALL.md) in the repo root for prereqs (Python 3.10+,
pipx, and on Windows: VC++ Redistributable).
