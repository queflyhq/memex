# Code of Conduct

memex adopts the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The full text is canonical at that link.

In short: be welcoming, kind, and constructive. Disagree about ideas, not people. Assume good intent — and when something goes wrong, repair it.

## Reporting

If you see behavior that violates the code of conduct — in issues, pull requests, discussions, or anywhere else — please report it privately to **conduct@quefly.com**. Reports are received only by Quefly's maintainers; identifying information is never shared without the reporter's consent.

We aim to acknowledge reports within 3 business days and resolve them within 30.

## Enforcement

Maintainers who don't follow or enforce this code of conduct in good faith may face consequences as determined by other maintainers.

## Scope

This code applies to all project spaces — repositories, issue trackers, pull request discussions, the project's official chat or email channels, and any time someone is officially representing the project in public.
